## Architecture rules
- Event data (sessions, speakers, sponsors) is fetched client-side via src/lib/data.ts: network-first with no-store and a 4s timeout, falling back to a localStorage copy (shown as offline data); the SW also uses NetworkFirst for these URLs. No backend in phase 1.
- Pure event rules (room fallback, overlaps, "now", .ics/Google links) live in src/lib/event.ts with tests in src/lib/event.test.ts; keep them free of React/browser globals.
- All UI strings go through src/locales/{fr,en}.json via useI18n(); never hardcode user-facing text.
- Service worker is generated by vite-plugin-pwa into dist/client and registered only via src/lib/pwa.ts (guards dev/preview/iframes); the manifest is static in public/.
- Likes are device-local (localStorage, src/lib/likes.ts) until accounts exist.
- Floor plan images live in public/plans/ (rdc.svg, etage-1.svg); replace files to update the map.
